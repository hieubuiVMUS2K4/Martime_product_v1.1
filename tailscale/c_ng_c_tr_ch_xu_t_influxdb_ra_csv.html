Bộ Công Cụ Trích Xuất Dữ Liệu Tàu Ra File CSV

Dựa trên file tín hiệu bạn cung cấp, hệ thống sẽ tạo Script để kéo trực tiếp các thông số (rudder, lat, lon, wind...) từ máy tàu qua Tailscale và lưu thành file Excel/CSV trên máy bạn.

Cấu hình nguồn tải

Cấu hình từ .env Chưa nạp

Tự động quét file .env cùng thư mục nếu chạy qua server local.

Đã bỏ qua cấu hình PostgreSQL theo yêu cầu. Dữ liệu sẽ được lưu thẳng thành file du_lieu_tau.csv.

Cấu trúc dữ liệu nhận diện từ file Excel của bạn

Hệ thống sẽ kéo dữ liệu thuộc 3 Measurement (nhóm) sau theo đúng thực tế trên tàu:

electric_data (11 tín hiệu)

  • rudder (Góc bánh lái)
  • propRpm (Vòng tua chân vịt)
  • mainRpm (Vòng tua máy chính)
  • rot (Tốc độ quay trở)
  • sog (Tốc độ trên mặt đất)
  • cog (Hướng đi trên mặt đất)
  • compass (La bàn)
  • fuelRack (Thanh răng nhiên liệu)
  • luboPress (Áp suất dầu nhờn)
  • volt (Điện áp)
  • amp (Dòng điện)

bridge_data (9 tín hiệu)

  • lat, lon (Tọa độ GPS)
  • fuelTotal (Tổng nhiên liệu)
  • fuelMain (Nhiên liệu máy chính)
  • fuelAux (Nhiên liệu máy phụ)
  • fuelDaily (Nhiên liệu hàng ngày)
  • fuelHourly (Nhiên liệu hàng giờ)
  • coolTemp (Nhiệt độ nước làm mát)
  • luboTemp (Nhiệt độ dầu nhờn)

engine_data (13 tín hiệu)

  • lat, lon (Tọa độ GPS phụ)
  • speedLog (Tốc độ qua nước)
  • windSpeed (Tốc độ gió)
  • windDir (Hướng gió)
  • rpm (Vòng tua động cơ phụ)
  • depth (Độ sâu)
  • roll (Độ nghiêng ngang)
  • fuel_level (Mức nhiên liệu)
  • exhaustTemp (Nhiệt độ khí xả)
  • startAirPress (Áp suất khí khởi động)
  • currentSpeed (Tốc độ dòng chảy)
  • currentDir (Hướng dòng chảy)

Script kéo dữ liệu về CSV

Script này sẽ gom tất cả dữ liệu từ các measurement trên và xuất ra 1 file CSV có cấu trúc: Thời gian | Tên Measurement | Tên Tín hiệu | Giá trị.

Cần cài thư viện: pip install influxdb-client


                        

                    


                    
                    

                        
Hướng dẫn chạy để lấy file

                        
                        
    
                            
  1. 
                                Tạo file mã nguồn: Tạo một file mới trên máy tính của bạn đặt tên là export_csv.py.
                            
    2. 
                            
  2. 
                                Dán code: Copy toàn bộ code ở Tab 2 và dán vào file vừa tạo.
                            
    3. 
                            
  3. 
                                Chạy lệnh: Mở Terminal (Command Prompt) tại thư mục chứa file và gõ:
                                
    python export_csv.py
    
                            
    4. 
                            
  4. 
                                Nhận kết quả: Đợi script chạy xong (mất khoảng vài giây đến vài phút tùy vào dung lượng dữ liệu). Bạn sẽ thấy một file tên là du_lieu_tau.csv xuất hiện trong cùng thư mục.
                            
    5. 
                            
  5. 
                                Bạn có thể mở trực tiếp file du_lieu_tau.csv này bằng Excel để vẽ biểu đồ và phân tích!
